Paper-derived facts cite AddressSanitizer (USENIX ATC 2012); the original paper, course instructions and private study translation are not part of this archive. See the [paper citation and scope](../docs/PROTOCOL.md#paper-and-reproduction-scope) and [formal results and public evidence](../docs/arm64-formal-results.md). The retained generation scripts document the original workflow. Module 4 figure regeneration requires the complete original local evidence tree, specified fonts and rendering dependencies; the v0.1 summary builder also requires the local source-paper PDF. Public CSVs alone are not these renderers' input. Historical logical `.local/` and run paths identify private provenance that is not bundled here. Public English plan revisions have different hashes from the original source-bound local plans. Module-owned image copies are the published entry; duplicate shared image paths mentioned in historical records are not required to read these PDFs. See each generation record for dependencies and commands. No new experiment or final `v1.0` release is included.
